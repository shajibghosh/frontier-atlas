# Changelog

## [1.0.0] — 2026-10-08

- Initial release of the FrontierAtlas open research catalog.
- 100 unresolved questions across 5 domains, 25 topics, and 50 subtopics.
- 88 linked reference records, each associated with one or more problems.
- Standalone searchable website with cascading filters, favorites, light/dark themes, deep links, and export to CSV, JSON and Markdown.
- Automated web release, structured-data exports, integrity validation and browser smoke tests.
- Research methodology, contributor guidance, source documents, and AI-assistance disclosure.
